# NeusomaHealing Practice — Next.js Frontend

Premium, responsive homepage implementation for NeusomaHealing Practice.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure

- `app/` — Next.js App Router pages and global styles
- `components/` — reusable UI and animation components
- `lib/home-data.ts` — content/data layer, ready to be replaced by API/CMS data
- `public/images/` — generated hero artwork
